.ds-scroll

Default container. Reserves the gutter with scrollbar-gutter: stable, so content never shifts when the thumb appears.

Thumb is gray-600 in dark, gray-300 in light, and lifts one step on hover.

Ten pixels wide with a three pixel transparent inset, so the visible thumb reads as a four pixel pill.

.ds-scroll-subtle

Thumb is transparent at rest and fades in on hover or focus-within.

For panels, sidebars and inspectors, where a resting scrollbar is visual noise against the chrome.

Hover this panel to see the thumb appear.

.ds-scroll-thin

Six pixels instead of ten, with a two pixel inset.

For dense lists, code blocks and anywhere the scroll region is narrow enough that a full-width thumb would crowd the content.

Narrows the webkit track directly, so it adds no token scope.

.ds-scroll-accent

Thumb takes the primary color instead of the neutral ramp.

Reserve it for a scroll region that is itself the focus of the view — a single long editor pane, not every panel on screen.

Rebrands automatically with the primary seed.
