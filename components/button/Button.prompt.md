Primary action control, used for the single most important action in a view.

```jsx
<Button variant="primary" size="md" onClick={save}>Save changes</Button>
```

Variants: `primary` (solid accent, one per view), `secondary` (bordered, default choice for most actions), `ghost` (no border/fill, toolbar-density actions), `danger` (destructive). Sizes: `sm` `md` `lg`. Pass `disabled` to mute and block clicks.
